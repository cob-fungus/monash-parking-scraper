# monash-parking-scraper
First GitHub project be me trying to download Monash University's parking vacancies data into a CSV 

The parking vacancies JSON is available publicly from the following URL:
https://home.student.monash/public/parkingAvailability.json

The scraper file is supposed to run every 5 minutes and collect that Monash data into the CSV in this same repository.
